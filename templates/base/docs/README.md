# docs

Decisions and research that outlive a single work item.

- `adr-<nnn>-<slug>.md` — one decision: context, decision, consequences, status (`active` / `superseded by ...`).
- `research-<slug>.md` — findings worth keeping; date and sources at the top.
- `perspective-<slug>.md` — how a subsystem works end to end, for a reader who has not seen the code.

Superseded files move to `../archive/` with a line in `../archive/INDEX.md`.
